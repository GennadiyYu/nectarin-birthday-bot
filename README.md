# Nectarin Birthday Bot

Telegram-бот для дней рождения сотрудников и клиентов, напоминаний и сборов на подарки.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/GennadiyYu/nectarin-birthday-bot)

## Установка

1. Нажмите **Deploy to Cloudflare** и войдите в Cloudflare.
2. Укажите `TELEGRAM_BOT_TOKEN` из BotFather, `BOT_USERNAME` без @ и `OWNER_USERNAME` — свой Telegram username без @. Замените значения `CHANGE_ME_WITHOUT_AT`.
3. `GEMINI_API_KEY` можно оставить пустым и добавить позже в секретах Worker. Кнопочное меню работает без Gemini.
4. Сохраните предложенную команду развёртывания `npm run deploy`: она применяет миграции D1 перед публикацией.
5. После успешной сборки откройте адрес Worker один раз — он зарегистрирует webhook Telegram. Откройте бота и нажмите Start с аккаунта владельца.

Cloudflare создаёт Worker и базу D1. Проверка дней рождения запускается каждый час; уведомления отправляются в 09:00 по Europe/Moscow.

## Возможности

- Управление сотрудниками, клиентами и юнитами кнопками в Telegram.
- Напоминания за 7, 3 дня и в день рождения.
- Сбор среди сотрудников юнита, кроме именинника, через личные сообщения.
- Кнопки «Участвую», «Перевёл», «Не участвую»; статус перевода отмечается сотрудником, банковские платежи бот не проверяет.
- Персональные ссылки привязки Telegram: сотрудник должен один раз открыть бота.
- Мягкое удаление записей с подтверждением.
- Свободные команды через Gemini; база хранится в D1.

В шаблоне создаётся нейтральный юнит «Основной юнит». Персональные данные сотрудников и клиентов отсутствуют в публичном репозитории: добавляйте их через Telegram или импортируйте отдельно в D1 после развёртывания. Автоматический импорт исходного списка в этом публичном шаблоне отключён.

Отдельные групповые чаты бот не создаёт. Напоминания и сборы работают в личных сообщениях.

## Проверки и локальный запуск

```bash
npm install
npm run typecheck
npm run db:migrate:local
npm run dev
```

Токены храните в `.dev.vars` локально и в секретах Worker в Cloudflare. Не добавляйте `.dev.vars`, выгрузки персональных данных или рабочую базу в Git.

При командах на естественном языке текст команды передаётся Gemini; кнопочные действия не требуют Gemini.
